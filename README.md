# قرارداد فرم

وب‌سایت فارسی راست‌چین برای معرفی و جست‌وجوی موضوعی نمونه قراردادها و فرم‌های خام.

## بانک قراردادها

- [صفحه جست‌وجوی بانک](pages/bank.html)
- [فهرست فایل‌های مستقل](bank/README.md)
- [دفتر منابع و روش گردآوری](bank/SOURCES.md)
- آرشیو اولیه شامل ۴۱ نمونه مستقل در دسته‌های املاک، کار، خدمات، کسب‌وکار، فناوری، خودرو، مالی، تجهیزات و فرم‌های عمومی است.

## ساختار پروژه

- `index.html` — صفحه نخست
- `pages/categories.html` — دسته‌بندی موضوعی و جست‌وجوی اولیه در فهرست
- `pages/how-to-use.html` — راهنمای انتخاب و استفاده
- `pages/about.html` — معرفی مأموریت و حدود کتابخانه
- `pages/contact.html` — فرم نمایشی بازخورد
- `assets/css/style.css` — طراحی واکنش‌گرا و اجزای مشترک
- `assets/js/main.js` — منوی موبایل و رفتار فرم نمایشی
- `assets/images/brand.svg` و `document-illustration.svg` — دارایی‌های گرافیکی محلی

## انتشار در GitHub Pages

در تنظیمات مخزن، بخش **Pages** را روی شاخه اصلی و پوشه ریشه (/​root) قرار دهید. فایل `404.html` برای مسیرهای ناموجود فراهم شده است.

## ملاحظات نسخه فعلی

- عکس‌های عکاسی در صفحه نخست از نشانی‌های عمومی Unsplash بارگذاری می‌شوند؛ فایل عکس‌های عکاسی هنوز در مخزن محلی ذخیره نشده است. دو تصویر برداری برند و سند، محلی هستند.
- فونت BYekan در صورت افزودن فایل `assets/fonts/BYekan.woff` استفاده می‌شود؛ در نبود آن، مرورگر از فونت‌های نصب‌شده محلی استفاده خواهد کرد.
- فرم تماس صرفاً نمایشی است و برای دریافت پیام باید به سرویس ارسال متصل شود.
- فهرست دسته‌ها نقشه اولیه آرشیو است و به معنی وجود یا تأیید تمام متن‌ها و فایل‌های قرارداد نیست.
- محتوا اطلاعات عمومی است و جایگزین مشاوره حقوقی متناسب با وضعیت خاص نیست.
