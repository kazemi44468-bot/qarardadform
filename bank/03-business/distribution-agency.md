# قرارداد نمایندگی فروش و توزیع

> **یادآوری:** الگوی عمومی و اولیه است و جایگزین بررسی حقوقی نیست. شرایط واقعی و قوانین لازم‌الاجرا باید پیش از استفاده بررسی شوند.

**شناسه:** BS-009

اصیل/تأمین‌کننده [ ] و نماینده/توزیع‌کننده [ ] توافق می‌کنند:
۱. کالا/خدمت و قلمرو نمایندگی [ ]؛ انحصاری یا غیرانحصاری بودن [ ].
۲. حدود اختیار نماینده در تبلیغ، مذاکره، دریافت وجه، امضای اسناد و اعلام قیمت [ ].
۳. اهداف فروش، حداقل سفارش و پیش‌بینی دوره‌ای [ ].
۴. قیمت خرید، تخفیف، حاشیه سود/پورسانت، شرایط پرداخت و اعتبار [ ].
۵. ثبت سفارش، تحویل، حمل، انتقال ریسک، مرجوعی و کالاهای معیوب [ ].
۶. استفاده از علامت تجاری، تبلیغات و محتوای تأییدشده [ ].
۷. محرمانگی، داده مشتری، تعارض منافع و رعایت مقررات مربوط [ ].
۸. مدت، تمدید، فسخ، فروش موجودی پس از خاتمه و تسویه مطالبات [ ].
