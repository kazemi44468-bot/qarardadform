# تصاویر محلی سایت

تصاویر عکاسی این پوشه با گردش‌کار GitHub Actions از منابع تصویری Unsplash دریافت و در مخزن ذخیره می‌شوند تا سایت پس از تکمیل دریافت از فایل‌های محلی استفاده کند.

- `contract-documents.jpg` — اسناد و قراردادها
- `property-buildings.jpg` — ساختمان و املاک
- `work-team.jpg` — همکاری حرفه‌ای
- `business-documents.jpg` — اسناد کسب‌وکار
- `technology-office.jpg` — فضای کاری فناوری
- `vehicle.jpg` — خودرو
- `finance-dashboard.jpg` — امور مالی و داده

منبع تصاویر: Unsplash (شناسه هر تصویر در فایل گردش‌کار `.github/workflows/download-images.yml` درج شده است). پیش از استفاده تجاری، مجوز جاری منبع و محدودیت‌های مربوط به اشخاص/علائم قابل شناسایی بررسی شود. تصاویر باید در خروجی مخزن باقی بمانند و وابستگی سایت به بارگذاری مستقیم از دامنه خارجی حذف شود.
